# Gamepad Chords device

`device/Gamepad Chords.amxd` is a Max MIDI Effect generated by `tools/build_amxd.py`.

## Use

1. Make sure Max can find `src/` (Max: Options > File Preferences > + > this repo's `src` folder).
2. In Live, put the device on a MIDI track **before** a synth.
3. Move the sticks. The wheels light up, the chord name shows, and the dials mirror the gamepad buttons.

Controls on the device: Key, Scale, Mode, Octave, Inversion, Hold, Bass, Settle (ms), Deadzone, Panic.

## If it will not load

The `.amxd` is hand-assembled and has not been opened in Max yet. If Live refuses it:

- Open `device/Gamepad Chords.maxpat` in Max; the Max console should say what it dislikes.
- Or use the hand-built patch in `docs/MAX_PATCH.md`: `[gamepad]` -> `[js gamepad_chords.js]` -> `[noteout]` is all that is needed now (the engine understands the gamepad's messages directly), plus `[jsui chord_wheel.js]` on the js's 3rd outlet for the display.
- If the wheel looks mirrored, send the js `invy 1` (flip vertical) and/or `invx 1` (flip horizontal). The device has Flip X / Flip Y switches for this.

## Regenerate

```
python tools/build_amxd.py
```
